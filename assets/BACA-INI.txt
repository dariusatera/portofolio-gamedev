Taruh gambar di folder ini, lalu tulis nama filenya di content.js.

Contoh:
  assets/aether-run.jpg
  assets/hero.jpg
  assets/foto-studio.jpg

Ukuran disarankan:
- Gambar pembuka (hero): 1600 x 1280 px atau lebih
- Cover game: 1600 x 900 px (16:9)
- Galeri: 1600 x 1000 px (16:10)
- Foto studio: 1200 x 1500 px (potret)

Format .jpg / .webp agar file ringan.
